# 🔐 Login-test

Um projeto prático e leve de interface de autenticação, desenvolvido com tecnologias web fundamentais. O objetivo é criar uma experiência de login limpa, funcional e responsiva.

-----

## 💻 Tecnologias

Este projeto foi construído "raiz", sem frameworks pesados, garantindo performance e facilidade de leitura:

  * **HTML5**: Estrutura semântica do formulário.
  * **CSS3**: Estilização personalizada, utilizando Flexbox/Grid para centralização e responsividade.
  * **JavaScript (Vanilla)**: Lógica de manipulação do DOM, validação de campos e alternância de visibilidade de senha.

-----

## 🛠️ Funcionalidades

  * **Design Moderno**: Interface focada no usuário com transições suaves.
  * **Validação de Input**: Feedback visual básico para campos obrigatórios.
  * **Responsividade**: Adaptado para visualização em dispositivos móveis e desktops.
  * **Toggle de Senha**: (Opcional, se implementado) Visualização da senha ao clicar no ícone de "olho".

-----

## 📸 Demonstração

Para visualizar o projeto, você pode simplesmente abrir o arquivo `index.html` em qualquer navegador ou utilizar a extensão **Live Server** no VS Code.

-----

## ✨ Como usar localmente

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Louvpiie/Login-test.git
    ```
2.  **Navegue até a pasta:**
    ```bash
    cd Login-test
    ```
3.  **Abra o arquivo principal:**
    Basta dar um duplo clique no arquivo `index.html`.
